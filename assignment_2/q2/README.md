# Assignment 2 - Question 2

## Question
Extend the application in Question 1 by adding a class that will maintain a list of shapes. You
will want only one list in the application, so use an appropriate design pattern to ensure this. As
items are added to the list, allow the user to move backwards and forwards through the list.

## Build and Run
This project uses CMake and Qt6 (Widgets).

Build:

```bash
# From assignment_2/q2
cmake -S . -B build
cmake --build build
```

Run the executable:

```bash
./build/q2
```
